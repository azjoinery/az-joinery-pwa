## 🚨 Important Notes

### GitHub Username
- Choose during signup
- Example: `allan-azjoinery`
- You'll need this for Git commands

### Environment Variables
- `NEXT_PUBLIC_API_URL` points to your FastAPI backend
- Currently set to `http://localhost:8000/api`
- Update when your backend is deployed

### First Deploy
- Takes 2-3 minutes
- Vercel shows "Building..."
- Then "Ready" with "Visit" button
- Click Visit → Your app is live!

### Auto-Deploy
- Push to GitHub → Vercel auto-deploys
- No manual steps needed
- 2-3 minutes per deploy
