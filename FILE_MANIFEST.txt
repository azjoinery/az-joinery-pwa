API ENDPOINTS REQUIRED
======================

Authentication:
  POST   /api/auth/login
    Input:  {email, password}
    Output: {access_token, token_type}

Users:
  GET    /api/users/me
    Output: {id, name, email, role, ...}

Daily Entries:
  GET    /api/entries/mine?date=YYYY-MM-DD
    Output: {id, counts, note, date, ...}
  POST   /api/entries
    Input:  {date, counts, note}
    Output: {id, ...}

Jobs:
  GET    /api/jobs
    Output: [{id, client, status, ...}]
  PATCH  /api/jobs/{id}
    Input:  {status, ...}
    Output: {id, ...}

Tasks:
  GET    /api/tasks?assigneeId={userId}
    Output: [{id, title, status, ...}]
  PATCH  /api/tasks/{id}
    Input:  {status}
    Output: {id, ...}

COMMON ISSUES & FIXES
====================

Issue: "Cannot connect to API"
  Fix: Check .env.local has correct NEXT_PUBLIC_API_URL

Issue: "Login fails"
  Fix: Verify credentials exist in database; check backend logs

Issue: "Build fails"
  Fix: Clear .next folder; reinstall node_modules; check TypeScript errors

Issue: "PWA won't install"
  Fix: Check manifest.json exists; clear browser cache; try again

Issue: "Slow performance"
  Fix: Check network throttling; optimize images; check API response times
